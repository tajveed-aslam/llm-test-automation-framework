# LLM test automation framework

A Python + Pytest framework for testing AI/LLM applications (prompts and RAG): reusable assertions, data-driven
cases, LLM-as-judge evaluation, safety tests, step-level **expected vs actual** reporting, and an auto-generated
Requirements Traceability Matrix.

Work in progress. See [docs/PLAN.md](docs/PLAN.md) for the architecture and the build phases.
