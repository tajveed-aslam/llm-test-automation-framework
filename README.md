# LLM test automation framework

A Python + Pytest framework for testing AI/LLM applications (prompts and RAG): reusable assertions, data-driven
cases, LLM-as-judge evaluation, safety tests, step-level **expected vs actual** reporting, and an auto-generated
Requirements Traceability Matrix.

**Status (2026-10-29): paused after Phase 1 of 9.** The demo AI app with 8 seeded bugs is built; the test framework
itself starts in Phase 2. See [docs/PLAN.md](docs/PLAN.md) for the architecture and phases, and
[docs/SEEDED_BUGS.md](docs/SEEDED_BUGS.md) for the bugs the framework will catch.
